# Simulated ISO/IEC 42001:2023 AI Management System Portfolio

**Status: supporting project files have not yet been published to this repository.**

This repository is intended to hold an educational, simulated AI Management System (AIMS) portfolio for a fictional organisation, **MaltaAI Solutions Ltd.**, an AI recruitment SaaS provider.

The project was developed as independent learning work. It is not a real client engagement, an accredited audit, a certification assessment, or evidence that an organisation conforms to ISO/IEC 42001.

## Scenario and planned portfolio contents

The fictional scenario includes AI-enabled recruitment functions:
- CV extraction
- Candidate ranking
- Candidate summaries
- Recruitment chatbot
- Recruitment analytics

The locally developed portfolio has been described as containing:
- AI system inventory
- AI risk register with 10 risks
- 8 impact assessments
- 10 risk-treatment records
- 5 supplier records
- 14 controls/evidence records
- 15 simulated audit checklist items
- 6 simulated audit findings

The simulated findings include issues relating to governance roles, residual-risk assessment, suppliers, human oversight, documentation and incident management. Findings are not evidence of real incidents or an actual audit.

## Important publication note

At present, this GitHub repository contains this README only. The supporting registers, assessments, control records, audit checklist and findings have **not** been committed here. The inventory above describes the local project state previously recorded by the author; it should not be treated as independently verifiable from this repository until the source files are published.

## Intended structure once source files are published

The repository should be organised into clearly named folders for:
1. Organisation context and AIMS scope
2. AI system inventory and lifecycle
3. AI risk assessment and treatment
4. AI impact assessments
5. Roles, responsibilities and human oversight
6. Supplier and third-party management
7. Control implementation and evidence tracking
8. Incident management
9. Internal audit checklist and simulated findings
10. Corrective actions and final portfolio report

Only files that actually exist and have been reviewed should be added. Do not upload personal data, confidential information, credentials, or unredacted evidence.

## Limitations

- MaltaAI Solutions Ltd. is fictional.
- All records and findings are simulated for educational purposes.
- The portfolio does not establish that controls are implemented or operating effectively.
- No formal audit, certification or conformity assessment has been performed.
- Risk acceptance, residual-risk decisions and management approvals must not be represented as approved unless supported by documented evidence.
